# Contract v1 schemas

These files preserve the frozen Phase 0 contract for validation and v1-to-v2 migration only. New objects must use Contract v2.

- `objects.schema.json`: v1 object frontmatter.
- `locator.schema.json`: v1 source locators.
- `relations.schema.json`: v1 global relation collection.
- `sqlite-projection-v1.sql`: v1 rebuildable projection.
